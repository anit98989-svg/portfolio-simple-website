🌐 Personal Portfolio Website

A simple and clean **personal portfolio website** built using **HTML and basic CSS**. This project was created to practice web development fundamentals and showcase personal information in a simple website.

## 📄 Pages

### 🏠 Home

The Home page introduces me and provides basic information about my profile, interests, skills, and projects.

### 📩 Contact

The Contact page contains my contact information and provides a way for visitors to get in touch with me.
